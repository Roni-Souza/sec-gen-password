\# 🔐 Secure Password Generator



Aplicativo desenvolvido com React Native e Expo para geração de senhas seguras.



\## Funcionalidades



\### ✅ Geração de Senhas



Gera senhas aleatórias contendo:



\- Letras maiúsculas

\- Letras minúsculas

\- Números

\- Caracteres especiais



\### ✅ Definição do Tamanho da Senha



O usuário pode informar a quantidade de caracteres desejada para a senha.



\### ✅ Copiar Senha



Permite copiar a senha gerada para a área de transferência do dispositivo.



\### ✅ Feedback Visual dos Botões



Os botões mudam de cor enquanto estão sendo pressionados, melhorando a experiência do usuário.



\### ✅ Indicador de Força da Senha



Feature adicional implementada para indicar o nível de segurança da senha:



| Caracteres | Força |

|------------|--------|

| 1 a 6 | Fraca |

| 7 a 12 | Média |

| 13 ou mais | Forte |



\## Tecnologias Utilizadas



\- React Native

\- Expo

\- TypeScript

\- Expo Clipboard



\## Como Executar



Instalar dependências:



```bash

npm install

```



Executar o projeto:



```bash

npm start

```



ou



```bash

npx expo start

```
